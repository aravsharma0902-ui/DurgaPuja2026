PUJA 2026 — GALLERY PAGE

Files:
- gallery.html
- gallery.css
- gallery.js

Setup:
1. Copy these three files into the same folder as index.html and events.html.
2. Keep the existing assets/durga-hero.png path unchanged.
3. The gallery expects these optional photographs:
   assets/gallery/pandal.jpg
   assets/gallery/competitions.jpg
   assets/gallery/community.jpg
   assets/gallery/details.jpg
   assets/gallery/anjali.jpg
   assets/gallery/cultural.jpg
   assets/gallery/memories.jpg
4. If an optional photograph is missing, the page automatically uses assets/durga-hero.png as a fallback.
5. The Team and Location links point to team.html and location.html. If those pages do not exist yet, change those links to # or index.html until you build them.

Features:
- Responsive maroon-and-antique-gold layout matching the provided style.css palette.
- Responsive mobile navigation.
- Category filters.
- Click-to-enlarge lightbox with previous/next controls and keyboard arrows.
- Does not modify index.html, style.css, script.js, countdown or Events files.
